 # TagMe - A community effort

<img width="1516" height="729" alt="image" src="https://github.com/user-attachments/assets/d8707374-1e3a-4e60-b77e-195bee29ba8f" />


TagMe is a cross-platform tag editor written in C# using Avalonia. It is easier to use than Picard, and not (yet) as bloated as Mp3Tag (which is also windows only afaik).

My plan is to make this project first-contribution friendly. I will post it only, and if it gets enough attention, I will let the community push the codebase further - otherwise I will just work on it on my own, whenever I feel like it.

Before you take my head off: the initial state of the code is intentionally this ugly. This provides a good amount of opportunity for some people who want to practice on a codebase they have never seen. And trust me, if you will ever work on a company's legacy code, it will be so much worse than this.

  ## How to contribute

Feel free to look at the code, and if you find something that could be done better, just give it a try. The only goal of any PR in this repo is simply "just make it better than you found it".

If you still don't know where to start, I already prepared some issues. Try to find one that seems like a fun solve 🙂

The only restriction is that AI generated code is not allowed. You are free to ask your agent/chatbot of choice, but write the code yourself.

 ## Discussion

If you have a question to ask, discussions are open here on GitHub, or at a dedicated [Discord server](https://discord.gg/QUsAy8nTmn)

Have fun coding! :)
